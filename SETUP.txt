SABERA: how to put it online (free, no server needed)

WHERE THINGS LIVE
- Website files (index.html, admin.html, style.css, fb.js, img folder): GitHub Pages (free hosting)
- Database (products, photos, offers, reviews): Firebase Firestore, Spark plan (free). This is your "server".

STEP A - GitHub Pages
1. github.com > New repository (name: sabera, Public). Upload all files and the img folder (Add file > Upload files).
2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. After 1-2 minutes your site is at https://YOURNAME.github.io/sabera/
   Your admin page is https://YOURNAME.github.io/sabera/admin.html (do not share this link).

STEP B - Firebase (database)
1. console.firebase.google.com > Add project (name: sabera). Skip Analytics.
2. Build > Authentication > Get started > Email/Password > Enable. Users tab > Add user (your email + password).
3. Build > Firestore Database > Create database > production mode.
   Rules tab > paste firestore.rules (write YOUR email inside) > Publish.
4. Project settings (gear) > Your apps > Web (</>) > register app > copy apiKey, authDomain, projectId, appId into fb.js, then upload fb.js again to GitHub.
5. Authentication > Settings > Authorized domains > add YOURNAME.github.io

STEP C - use it
- Open admin.html on your phone, login, add products with photos, offers, settings.
- Customers see everything on index.html and can leave star reviews. You can delete any review in admin > Reviews.

OPTIONAL: put official logos in img/ named whatsapp.png, easypaisa.png, jazzcash.png, upaisa.png and they replace the simple icons.
